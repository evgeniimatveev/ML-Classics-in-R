# 📈 Section 2: Regression

Predicting a number: from a straight line to forests of trees, each on its own small dataset.

> Open `ML-Classics-in-R.Rproj` in RStudio first: it makes paths such as `data/mall.csv` resolve. Packages are loaded with `library()` at the top of each script.

| # | Script | Topic | Dataset | Notes |
|:-:|--------|-------|---------|-------|
| 1 | [`01-simple-linear-regression.R`](01-simple-linear-regression.R) | Simple linear regression: salary from years of experience | `salary-data.csv` |  |
| 2 | [`02-multiple-linear-regression.R`](02-multiple-linear-regression.R) | Multiple linear regression: profit of 50 startups, VIF check for multicollinearity | `50-startups.csv` |  |
| 3 | [`03-polynomial-regression.R`](03-polynomial-regression.R) | Polynomial regression: salary by position level | `position-salaries.csv` |  |
| 4 | [`04-svr.R`](04-svr.R) | Support Vector Regression compared with linear regression | `position-salaries.csv` |  |
| 5 | [`05-decision-tree-regression.R`](05-decision-tree-regression.R) | Decision tree regression (and a random forest) on California housing prices | `housing.csv` |  |
| 6 | [`06-random-forest-regression.R`](06-random-forest-regression.R) | Random forest regression: salary by position level | `position-salaries.csv` |  |
